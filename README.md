# Raíz Atelier

Independent bakery storefront for Raíz Atelier in Cherrywood, Dublin.

Website: https://petitemachine.github.io/raiz-atelier/

The portfolio version remains at https://petitemachine.github.io/AdrianaMarcialPortfolio/RAIZ_ATELIER/raiz-atelier.html.

Edit index.html for page content, raiz-language.js for Spanish translations, order-summary.js for prices, order-schedule.js for dates, and checkout-review.js for the combined order review. Orders open WhatsApp; availability and payment are confirmed by the bakery.

GitHub Pages serves main from the repository root.
